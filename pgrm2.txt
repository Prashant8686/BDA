Paste the following complete Java program:

import java.net.URI;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.FileStatus;
import org.apache.hadoop.fs.FileSystem;
import org.apache.hadoop.fs.FSDataInputStream;
import org.apache.hadoop.fs.FSDataOutputStream;
import org.apache.hadoop.fs.Path;

public class HdfsDemo {

    public static void main(String[] args) throws Exception {

        String uri = "hdfs://namenode:8020";

        Configuration conf = new Configuration();

        FileSystem fs =
            FileSystem.get(URI.create(uri), conf);

        Path file =
            new Path("/user/student/quangle.txt");

        FSDataOutputStream out =
            fs.create(file);

        out.writeBytes(
            "On the top of the Crumpetty Tree\n");

        out.writeBytes(
            "The Quangle Wangle sat\n");

        out.close();

        System.out.println(
            "Wrote file: " + file);

        FSDataInputStream in =
            fs.open(file);

        byte[] buffer = new byte[32];

        in.read(buffer);

        System.out.println(
            "From start : " +
            new String(buffer).trim());

        in.seek(33);

        byte[] buf2 = new byte[32];

        in.read(buf2);

        System.out.println(
            "After seek : " +
            new String(buf2).trim());

        in.close();

        FileStatus st =
            fs.getFileStatus(file);

        System.out.println(
            "Length : " +
            st.getLen() +
            " bytes");

        System.out.println(
            "Replication: " +
            st.getReplication());

        System.out.println(
            "--- listStatus /user/student ---");

        for (FileStatus s :
             fs.listStatus(
                 new Path("/user/student"))) {

            System.out.println(
                " " + s.getPath().getName());
        }

        System.out.println(
            "--- globStatus *.txt ---");

        for (FileStatus s :
             fs.globStatus(
                 new Path("/user/student/*.txt"))) {

            System.out.println(
                " " + s.getPath().getName());
        }

        fs.close();
    }
}

Save and close Notepad.

VIVA EXPLANATION
===========================================================

AIM:

To perform HDFS file operations using the Hadoop Java
FileSystem API.


EXPLANATION:

This program connects a Java program to HDFS using the
NameNode address hdfs://namenode:8020.

It creates a file called quangle.txt inside the
/user/student directory.

It writes text into the file using FSDataOutputStream.

It reads the file using FSDataInputStream.

The seek() method moves the file pointer to a particular
byte position and reads the data from that position.

getFileStatus() is used to obtain the file length and
replication factor.

listStatus() is used to list files in the directory.

globStatus() is used to search files using a pattern such
as *.txt.

Therefore, the program demonstrates basic HDFS file
operations using the Hadoop Java FileSystem API.


IMPORTANT METHODS:

FileSystem.get()
    -> Connects to HDFS.

fs.create()
    -> Creates a file in HDFS.

FSDataOutputStream
    -> Writes data to the HDFS file.

fs.open()
    -> Opens an HDFS file for reading.

FSDataInputStream
    -> Reads data from the HDFS file.

seek()
    -> Moves the file pointer to a specific position.

getFileStatus()
    -> Gets file information.

listStatus()
    -> Lists files/directories.

globStatus()
    -> Searches files using a pattern.

fs.close()
    -> Closes the HDFS connection.


COMMON VIVA QUESTIONS:

Q1. What is HDFS?

Answer:
HDFS stands for Hadoop Distributed File System. It is used
to store large amounts of data in a distributed environment.


Q2. What is NameNode?

Answer:
NameNode manages the metadata and file structure of HDFS.


Q3. What is DataNode?

Answer:
DataNode stores the actual data blocks.


Q4. What does fs.create() do?

Answer:
It creates a new file in HDFS.


Q5. What does fs.open() do?

Answer:
It opens an HDFS file for reading.


Q6. What does seek() do?

Answer:
It moves the file pointer to a specified byte position.


Q7. What does getFileStatus() do?

Answer:
It provides information about the file such as file length
and replication factor.


Q8. Difference between listStatus() and globStatus()?

Answer:
listStatus() lists files and directories.

globStatus() lists files matching a specified pattern.


Q9. What is replication factor?

Answer:
Replication factor specifies how many copies of an HDFS
data block are maintained.

In this program the replication factor is 1.


Q10. What is the main purpose of this program?

Answer:
The main purpose is to demonstrate HDFS file operations
using Java FileSystem API.
